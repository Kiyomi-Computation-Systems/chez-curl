* Chez Scheme HTTP Client

[[https://github.com/Kiyomi-Computation-Systems/chez-curl/actions/workflows/ci.yml][https://github.com/Kiyomi-Computation-Systems/chez-curl/actions/workflows/ci.yml/badge.svg]]

An HTTP Client for Chez Scheme built on libcurl.

#+begin_quote
✨ *AI Disclosure:* LLMs are used extensively in the planning and development of this project.
#+end_quote

chez-curl is an HTTP client for Chez Scheme. It binds libcurl through Chez's
foreign interface, and checks what you hand it before any of it reaches C.

It has two levels:

- *=(http-client)=, the high level:* a session, and a call per request,
  =http-get=, =http-post= and the rest. It follows redirects by its own rules,
  retries by a policy you give it, keeps cookies, sends forms and multipart
  bodies, and streams both ways.
- *=(curl)=, the low level:* a request is data, an engine runs it, and a token
  hands you the response. =(http-client)= is built on it.

*One engine thread runs many requests.* An engine is one thread that drives
every transfer submitted to it at once, so making many requests at once
takes no thread per request: a request group, or many tokens, on your one
thread.

** Status

chez-curl 0.1.0 is its first release. Its suites run on:

- Linux on amd64, on curl's own 7.85.0 and 8.23.0, built from source, Ubuntu's
  8.5.0 with OpenSSL and with GnuTLS, and Guix's 8.20.0;
- macOS on arm64, with Apple's libcurl 8.7.1.

Linux on arm64 and macOS on amd64 have not run them. Windows is not
supported. [[file:docs/libcurl-versions.md][What varies by libcurl]] lists each behaviour that differs by
version.

** Requirements

- Chez Scheme 10.4.0 or later, built with threads
- libcurl 7.85.0 or later, built with TLS
- Node.js 20 or later, for the tests

** Installing

Clone the repository, and put its =src= directory on Chez's library path.
There is nothing to build: libcurl is loaded when your program runs.

#+begin_src sh
git clone https://github.com/Kiyomi-Computation-Systems/chez-curl.git
scheme --libdirs chez-curl/src --program app.sps
#+end_src

chez-curl finds the system's libcurl; =CHEZ_CURL_LIBCURL= names another, by
its absolute path. The [[file:docs/quickstart.md][quick start]] says more.

** A taste

=examples/quick-start.sps=, given the test server's base URL, with no trailing
=/= ([[file:docs/quickstart.md][quick start]]):

#+begin_src scheme :example examples/quick-start.sps
(import (rnrs) (http-client))

(define base (cadr (command-line)))

(call-with-http-session
 (lambda (session)
   (let ((response (http-get session (string-append base "/status/200"))))
     (display (http-response-status response))
     (newline)
     (display (http-response-text response)))))
#+end_src

[[file:examples/][examples/]] holds nine more, each run by =make test=.
